Leonida Ledger — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: a checklist with saved progress, a four-stage roadmap to the platinum, the four missable trophies flagged, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is plain static files under `app/` — no build step, no network requests. Progress is saved in the browser (localStorage) and can be exported to a JSON file and imported back.
